# Security policy

## Supported versions

Only the latest release gets security fixes. gemseo-gantry is still pre-1.0, so fixes ship in a new release rather than being backported.

## Reporting a vulnerability

Please don't report vulnerabilities in public issues. Use [private vulnerability reporting](https://github.com/axwide/gantry/security/advisories/new) instead.

It helps to include:

- the gemseo-gantry version you're on
- steps or a problem-definition file that reproduce the issue
- what an attacker could do with it

You'll get a reply in the advisory thread. If the issue is confirmed, the fix and the advisory are published together.
